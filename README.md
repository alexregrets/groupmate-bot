# groupmate-bot

Telegram-бот для учебной группы. Проверяет один или несколько общих IMAP-ящиков и присылает короткую карточку письма в чат или топик. С ИИ в шапке стоят предмет, преподаватель и срок, ниже не больше трёх заданий по 140 символов, кнопки «Читать целиком» и «промпт на старт». Вложения приходят следом, документы группируются по десять. Без ИИ карточка показывает тему, отправителя и первые 300 символов письма. Полный текст доступен из локального архива по кнопке, длинный текст разбивается на сообщения.

Утром бот показывает сегодняшние пары и домашку, вечером завтрашние. `/schedule` открывает день, `/week` неделю. Расписание приходит через адаптер `ruz` или из обычного JSON-файла с датами. Если данных нет, бот говорит об этом и не объявляет выходной. Пустой пинг не отправляется.

Команда `/hw` хранит домашку в SQLite. Задания извлекаются из писем, а по отдельному флагу из сообщений чата. Утром в день сдачи радар присылает одну строку на задание с кнопкой «сдал»: отметка личная, задания других участников сохраняются. LLM работает с любым OpenAI-совместимым endpoint, по умолчанию выключен. `/cost` показывает администратору расход токенов и денег; дневной бюджет останавливает следующие запросы, предупреждения приходят в личку. Всё работает одним процессом.

## Быстрый старт за 15 минут

Нужен компьютер или сервер с Docker Engine и Docker Compose. Все адреса и числа в примерах выдуманы.

1. Создайте бота в Telegram через `@BotFather`, командой `/newbot`. Сохраните выданный токен.
2. Добавьте бота в свою группу администратором с правом отправлять сообщения и документы. Для форумов выберите топики почты и пингов. В `@BotFather` выполните `/setprivacy`, выберите бота и `Disable`, если хотите извлечение домашки из обычных сообщений. После смены privacy удалите бота из группы и добавьте снова. Администраторы уже получают сообщения группы.
3. Подготовьте числовой ID группы и, при необходимости, ID топика. Если ID неизвестен, временно оставьте в конфигурации пример `-200`, запустите бота и отправьте `/where` в нужной группе или теме. Бот ответит ID текущего чата и темы, после этого замените значение и перезапустите его. Для `/cost` узнайте свой user ID через `/where` в личке с ботом.
4. В настройках почты включите IMAP и создайте отдельный пароль приложения. Обычный пароль аккаунта может не работать. Доступ к общему ящику должен быть согласован с группой.
5. В каталоге проекта создайте настройки и расписание:

   ```sh
   cp .env.example .env
   cp schedule.example.json schedule.json
   ```

   В Windows PowerShell используйте `Copy-Item .env.example .env` и `Copy-Item schedule.example.json schedule.json`.

6. Откройте `.env`. Обязательно замените `TELEGRAM_BOT_TOKEN` и `TELEGRAM_GROUP_CHAT_ID`. Для почты заполните `IMAP_HOST`, `IMAP_USER`, `IMAP_PASSWORD`. В `schedule.json` замените выдуманные пары и даты на свои. Для `ruz` выберите `SCHEDULE_PROVIDER=ruz` и свой `RUZ_GROUP_ID`; файл `schedule.json` всё равно нужен для bind mount Compose. ИИ для старта не нужен.
7. Запустите:

   ```sh
   docker compose up -d --build
   docker compose logs --tail=50 groupmate
   ```

8. Отправьте `/schedule` и `/hw` в группе. Первое подключение к ящику запоминает границу и не рассылает старые письма. Отправьте новое тестовое письмо, подождите один интервал опроса и проверьте карточку и вложение. Для повторной настройки выполните `docker compose up -d`, Compose пересоздаст контейнер при изменении `.env`.

Чтобы бот работал только с расписанием, оставьте `IMAP_USER` пустым и `MAIL_SOURCES=[]`. Чтобы включить ИИ-карточки, задайте одновременно `AI_API_URL`, `AI_API_KEY`, `AI_MODEL`. Ответы на прямое обращение отдельно включаются через `AI_REPLIES=1`. Системный промпт для них находится в `prompts/assistant.md`.

## Команды

| Команда | Результат |
| --- | --- |
| `/where` | ID текущего чата, топика и вашего пользователя для настройки |
| `/schedule` или `/schedule завтра` | Расписание дня и домашка |
| `/schedule вт`, `/schedule 25.11`, `/schedule 2026-11-25` | Конкретный день |
| `/week`, `/week 2026-11-23`, `/schedule неделя` | Неделя с понедельника |
| `/hw` | Задания на ближайшие 14 дней, кроме лично отмеченных |
| `/hw 25.11` | Домашка на дату |
| `/hw завтра прочитать главу 3` | Добавить домашку в этот чат |
| `/cost` | Токены и стоимость сегодня, за 7 и 30 дней, только ADMIN_CHAT_ID в личке |

Без ИИ извлекаются строки с действием («сдать», «решить», «прочитать», «подготовить», «выполнить», «задание») и явной датой `18.11`, `18.11.2026` или `2026-11-18` в той же строке. Остальное добавляется через `/hw`. ИИ тоже не должен выдумывать срок: задания без понятной даты не попадают в радар. Задания с общим сроком письма наследуют его. Дата без года считается ближайшей будущей относительно письма, поэтому для прошедших сроков лучше указывать год.

## Настройки

Все переменные перечислены в `.env.example` с комментариями. Флаги принимают только `0` и `1`. Пустое время пинга выключает его.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | обязательно | Токен BotFather |
| `TELEGRAM_GROUP_CHAT_ID` | обязательно | Основная группа |
| `ADMIN_CHAT_ID` | пусто | User ID администратора, который открыл личку с ботом |
| `TIMEZONE` | Europe/Moscow | Часовой пояс IANA |
| `STATE_DIR` | state | Каталог SQLite, в Compose задан /app/state |
| `PING_THREAD_ID` | пусто | Топик пингов и радара |
| `MAIL_THREAD_ID` | PING_THREAD_ID | Топик основного ящика |
| `IMAP_HOST` | imap.example.test | IMAP TLS, порт 993 |
| `IMAP_USER` | пусто | Адрес основного ящика; пусто выключает его |
| `IMAP_PASSWORD` | пусто | Пароль приложения |
| `IMAP_FOLDER` | INBOX | Почтовая папка |
| `MAIL_SOURCES` | [] | Дополнительные ящики, JSON ниже |
| `POLL_INTERVAL_SECONDS` | 60 | Интервал опроса, секунды |
| `FORWARD_HISTORY` | 0 | Разослать историю при первом запуске |
| `TEACHER_SENDER_FILTER` | пусто | Разрешённые фрагменты адресов через запятую |
| `SENDER_BLOCKLIST` | пусто | Запрещённые фрагменты адресов через запятую |
| `SCHEDULE_PROVIDER` | json | json или ruz |
| `SCHEDULE_FILE` | schedule.json | Файл JSON; в Compose /app/schedule.json |
| `RUZ_GROUP_ID` | 0 | Обязателен для ruz; в примере 12345 |
| `RUZ_REFRESH_MINUTES` | 180 | Срок кеша расписания |
| `MORNING_PING` | 07:30 | Пинг сегодняшнего дня |
| `EVENING_PING` | 20:00 | Пинг завтрашнего дня |
| `HW_FROM_MAIL` | 1 | Извлекать домашку из писем |
| `HW_FROM_CHAT` | 0 | Извлекать домашку из чата |
| `RADAR` | 1 | Радар дедлайнов утром |
| `AI_REPLIES` | 0 | Ответы на @упоминание и reply боту |
| `AI_API_URL` | пусто | Полный URL /chat/completions |
| `AI_API_KEY` | пусто | Секретный ключ LLM |
| `AI_MODEL` | пусто | Модель провайдера |
| `AI_DAILY_LIMIT_USD` | 0.5 | Локальный дневной бюджет; 0 блокирует ИИ |
| `COST_ALERT_USD` | 0.1 | Порог предупреждения об остатке бюджета или ключа |
| `AI_INPUT_USD_PER_MILLION` | 0 | Цена миллиона входных токенов |
| `AI_OUTPUT_USD_PER_MILLION` | 0 | Цена миллиона выходных токенов |

Если endpoint возвращает `usage.cost`, бот использует эту сумму. Иначе задайте цены токенов вашего провайдера. При неизвестной стоимости уже сделанного запроса следующие LLM-запросы блокируются до следующего дня или настройки цен для новых запросов; старую неизвестную стоимость цены задним числом не пересчитывают. `/cost` показывает «стоимость неизвестна», а не ноль. Это локальный сторож: текущий запрос может пересечь лимит, поэтому жёсткий потолок выставляйте также у провайдера. Для OpenRouter дополнительно проверяется остаток ключа. Без ключа LLM-запросов и проверок баланса нет.

Дополнительные ящики задаются одной строкой в `.env`:

```dotenv
MAIL_SOURCES='[{"key":"extra","imap_host":"imap.example.test","imap_user":"extra@example.test","imap_password":"replace_me","imap_folder":"INBOX","targets":[{"chat_id":-300,"thread_id":7}]}]'
```

Ключи уникальны: `a-z`, цифры, `_`, не больше 16 символов; `main` занят основным ящиком, если он включён. У каждого ящика независимый UID и архив. `targets` может содержать несколько чатов. Если список пропущен, используется основная группа. Домашка из письма сохраняется только в чатах его targets. Кнопка открытия проверяет чат и топик источника. Радар работает также в дополнительных чатах, в первом настроенном для чата топике; в основной группе использует PING_THREAD_ID. Личные отметки «сдал» не меняют групповой пинг. После перезапуска пропущенный пинг догоняется только в пределах двух часов от настроенного времени.

## Расписание JSON и свой вуз

`schedule.example.json` содержит полностью выдуманные данные. Обязательный корень: объект `days`, где ключи являются датами `YYYY-MM-DD`, значения списками пар. У пары обязательны строки `start`, `end` в `HH:MM`, `subject`; необязательны `teacher`, `room`, `kind`, `status`, `note`, `replaces`. Пары сортируются по началу. `[]` означает, что занятий точно нет. Отсутствующая дата означает, что данных нет. Повторения по неделям нет: заполните нужные даты, включая выходные. Файл перечитывается при запросе; после правки файла при bind mount при необходимости перезапустите контейнер.

Для нового источника реализуйте `ScheduleProvider` из `groupmate/schedule.py`: асинхронный метод `week(day)` возвращает словарь ISO-дат недели с понедельника, значения списки пар того же формата. `None` или отсутствующий день означает неизвестное расписание. Затем подключите класс в выборе провайдера в `groupmate/bot.py` и разрешите его имя в `groupmate/config.py`. Встроенный `RuzScheduleProvider` показывает пример HTTP-адаптера, кеша SQLite, объединения подгрупп и работы при сбое API. Адрес API находится только в `groupmate/ruz.py`. ID вашей группы задаётся через `RUZ_GROUP_ID`, в примерах используется `12345`.

## Запуск без Docker и systemd

Python 3.12 или новее:

```sh
python -m venv venv
. venv/bin/activate
pip install -r requirements.txt
python main.py
```

В PowerShell активируйте `venv\Scripts\Activate.ps1` либо вызывайте `venv\Scripts\python.exe main.py` напрямую. Настройки лежат в `.env` в рабочем каталоге. Для systemd положите проект в `/opt/groupmate-bot`, создайте системного пользователя и группу `groupmate`, дайте ему чтение проекта и `.env`, установите зависимости в `/opt/groupmate-bot/venv`. Скопируйте `deploy/groupmate.service` в каталог юнитов systemd и включите сервис. `StateDirectory` создаёт `/var/lib/groupmate` с нужным владельцем; переменная сервиса имеет приоритет над `.env`. Одновременно запускайте только один экземпляр бота на токен и базу.

## Безопасность и данные

Бот видит сообщения доступных ему чатов. При `HW_FROM_CHAT=1` текст сообщений передаётся настроенному LLM, если он включён. При включённом LLM туда также уходит текст новых писем для карточек. Содержимое сообщений обрабатывается как данные. Не подключайте чужой ящик и не добавляйте в targets чаты, которым нельзя читать его почту.

Токен Telegram, пароли IMAP и ключ LLM хранятся только в `.env`. Файл исключён из Git и Docker build context. Не публикуйте SQLite и дампы: в базе лежат полные тексты писем, домашка, ID чатов и отметок. В Compose база хранится в именованном томе `groupmate-state`, на обычном запуске в `STATE_DIR/groupmate.db`. Сохраняйте этот том между обновлениями. При потере базы первый запуск снова пропустит старую почту, а кнопки старых карточек потеряют архив. Пароль приложения можно отозвать отдельно от основного пароля.

IMAP использует TLS, таймаут 30 секунд и до трёх попыток при обрыве с паузами 2 и 4 секунды. После неудачного цикла опрос продолжается. Отправленный target помечается в SQLite; при частичной неудаче повторяются только ещё не подтверждённые targets. UID продвигается после успешной доставки карточки и вложений всем targets. При аварии между отправкой и записью подтверждения возможен повтор. Вложения больше 50 МБ пропускаются с уведомлением. История доставки и архив пока не очищаются автоматически.

## Проверка

```sh
python run_offline_tests.py -q -p no:cacheprovider
```

Раннер использует `venv`, если он создан, отключает загрузку `.env` и сторонних pytest-плагинов, запрещает внешние сокеты, DNS и доступ к рабочему `state/`. Локальные сокеты Windows asyncio разрешены. Тесты используют временную SQLite и синтетические письма, расписания, преподавателей и ID. Боевые API для тестов не нужны. `.task/` содержит локальное задание и исключена из публикации и образа.
